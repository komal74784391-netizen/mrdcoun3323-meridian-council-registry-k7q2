# Meridian Trade Council - Council Membership Registry

Public data repository for the council membership directory of the Meridian Trade Council.

## Editions

- `registry/edition-2024-12.json` - edition in force for the FY2025 reporting year.
- `registry/edition-2026-03.json` - current draft edition; membership committee reassignments are pending ratification.

Open `index.html` for a human-readable view of both editions, or read the JSON files directly.

The registry maps member codes to council codes. Member revenue figures are not published here; they are distributed separately in the annual member extract.
